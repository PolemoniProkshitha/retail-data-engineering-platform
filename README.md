
# Retail Data Engineering & Analytics Platform

## Project Overview

An end-to-end Data Engineering portfolio project
that demonstrates data ingestion, transformation,
validation, storage, and analytics using modern
Data Engineering tools.

## Business Problem

A fictional retail company needs a reliable data
pipeline to process daily sales data and generate
analytics-ready datasets.

## Technology Stack

- Python 3.12
- PostgreSQL
- SQL
- Pandas
- PySpark
- Azure Data Factory
- Azure Data Lake Storage
- Git and GitHub

## Project Status

Phase 1: Environment setup and foundations.

## Dataset

Kaggle Store Sales - Time Series Forecasting.

## Architecture

Planned: Source Data -> Ingestion -> Transformation
-> Data Storage -> Analytics
